⚛ Awesome Periodic Table – Help

🔍 Getting started
  • Type anything into the search bar — no Enter needed, results filter as you type.
  • Non-matches stay visible but blurred; matches get a golden glow.
  • A single result auto-shows its properties, unless you already have an element locked or in comparison mode.
  • / jumps to the search bar from anywhere.
🖱 Mouse modes
  • Hover an element to inspect it — this works the same whether the table is filtered or not.
  • Left-click selects an element and locks the Details panel so hovering other elements won't overwrite it. Left-click the same element again to deselect.
  • Right-click selects an element and starts comparison mode without locking Details — hover other elements to compare them against the selected one. Right-click the same element again to deselect.
  • With an element selected, clicking it with the opposite button keeps that element selected and just switches modes. Clicking a different element resets first, then selects the new one in whichever mode you clicked with.
  • Esc clears selection, locking and comparison mode at any time.
📖 Search history
  • Because search is incremental, a query is recorded once you stop typing for about a second — or immediately when you press Enter or leave the field.
  • Queries that match zero elements are skipped automatically — typing "boi" on your way to "boils" never clutters your history. Click the history button to force-save the current text anyway.
  • Retyping the exact same query as your last entry (ignoring case and extra spaces) never creates a duplicate — safe to click the history button repeatedly without spamming entries.
  • ↑ / ↓ browse history. Pressing ↓ past the newest entry returns you to a blank line, bash-style — and an unsubmitted draft you were typing is restored if you come back.
  • The counter on the history button reads position / total: 0/0 when empty, 0/7 with seven stored entries, 2/7 while the second entry is loaded.
  • Ctrl+R (or clicking 📕) opens reverse-i-search: type to find a past query, ↑/↓ to walk through matches, Enter or Tab to accept, Esc to cancel and restore what you had.
  • Shift+Del deletes the history entry currently loaded (or highlighted in i-search) — no confirmation.
  • Press and hold the history button for 2.2 s to clear everything; the button fills bottom-to-top as it arms, and releasing early cancels.
  • History holds 50 entries; when full the oldest one drops off. It is saved automatically and restored on your next visit.
✓ Autocomplete
  • Typing two or more letters of a word suggests the rest inline: type va and the field shows vanadium with the guessed tail selected.
  • Keep typing to refine it — your keystrokes replace the selected tail. Tab or Enter accepts the whole word, → also accepts.
  • Works anywhere in the line, not just at the end — editing "boils above 4000k and not radioactive" by inserting "solid below 3000f and " in the middle still suggests each word as you type it there.
  • Backspace on a live suggestion doesn't just clear the ghost text — it treats the suggestion as if it were never there and removes one real character too, so ca[lcium] → Backspace → c directly. ← cancels the suggestion without deleting anything.
  • Press Space to dismiss the guess and start a new word; erasing that space brings the suggestion back for the previous word, wherever it is in the sentence.
  • Suggestions are ranked by likelihood — element names and common keywords first, and phrases you have searched before are promoted above the rest.
  • Tab is only intercepted when a suggestion is showing; otherwise it moves focus normally.
🌡 Temperature
  • Drag the slider or use −/+ to change temperature and phase badges live. ↻ resets to 25 °C.
  • Click the temperature reading to type an exact C/F/K value; confirm with Enter or ✓, cancel with Esc.
  • Shift+↑/↓ changes temperature from anywhere; T opens the editor.
🧩 Query operators: AND, OR, commas, NOT
  • AND requires every condition: liquid and gas is impossible, so it returns zero.
  • Commas normally behave exactly like and (transition, density above 10 narrows). The exception: when every comma-separated part names a specific, mutually-exclusive item, intersecting them would give nothing — so gold, silver, platinum lists all three instead.
  • OR always unions alternatives: noble gas or halogen.
  • NOT can prefix any individual term and mixes freely with the rest: transition and not toxic, transition, not toxic, density above 5, and transition not toxic all mean the same thing.
  • Connector words are optional in many places — metalloids more dense than B works without writing and.
📊 Comparisons and ranges
  • Compare against a number or against another element: density above 10, melts above Fe, heavier than gold.
  • Ranges accept both forms too: density between 5 and 10, density between silver and gold, boils between Po and Osmium. Range bounds are inclusive, so the reference elements match their own range.
  • Element references accept symbol, name, or Latin name: Fe, iron, Ferrum.
  • Temperatures accept units: solid below 1000C, melts above 500 K, boils below 200F.
  • Melting verbs: melt, freeze, solidify, liquefy. Boiling verbs: boil, condense, vaporize, evaporate.
🏆 Superlatives
  • Ask for extremes directly: densest, most dense, heaviest, lightest, most electronegative, highest melting point, lowest boiling point, most conductive, most abundant, earliest discovered.
  • Add a qualifier to rank within a group: most dense radioactive element, densest transition element, lightest nonmetal.
  • Singular returns the single winner; writing elements (plural) returns the top ten: most dense elements.
🏷 Categories, phases and hazards
  • Category names work singular, plural or hyphenated: metalloid, metalloids, noble gas, noble gases, post-transition, post transition metals.
  • metal/metals matches every metallic category (alkali through actinide) and excludes metalloids.
  • Phases are evaluated at the current temperature: solid, liquid, gas, or explicitly liquid at 25C.
  • toxic means Moderate toxicity or worse. Hazard words (hazard, hazardous, dangerous) mean toxic or radioactive.
  • radioactive and stable split the table by half-life.
🌐 Discovery and occurrence
  • Discovery filters cover who and where it was first found, not where it is mined: discovered in Sweden, from Sweden, discovery country: Sweden.
  • USA and United States are interchangeable, as are UK and United Kingdom.
  • Years: after 1900, before 1800, year between 1800 and 1900. Leading words like “discoveries” are optional.
  • Occurrence/source text is searched too, including broad regions such as asia, europe or south america.
⚡ Property shortcuts
  • en electronegativity · tc thermal conductivity · ec electrical conductivity · e0 standard electrode potential.
  • mass · density · melt/melts · boil/boils · heat specific heat · abundance crustal abundance · ocean abundance.
  • Electrical and thermal conductivity are distinct: ec targets electrical, tc targets thermal, and plain conductivity searches either.
  • Labelled form works for exact values: category: transition, toxicity: High, magnetism: Paramagnetic, oxidation: 2, electrical: Conductor.
  • Ionization energy has no short alias yet — write it out.
⚛ Details panel & extra data
  • Shift+click a clickable property or element to add/remove it as a comma-separated filter without replacing your current query.
  • Plain clicking a value replaces the query with that filter.
  • Ionization energies are hover-only quick tables; the whole value is one hover target for up to four values.
  • Hover-only values such as …, ionization energies and isotopes use a help cursor.
  • Magnetism is computed dynamically from atomic number and the current temperature.
⌨ Keyboard reference
  • / focus search · Esc clear query, then switch to table mode
  • ↑↓ search history · Ctrl+R history search · Shift+Del delete entry
  • Tab accept autocomplete (only when a suggestion is showing)
  • ←→↑↓ move around the table · Enter select/deselect
  • Shift+↑↓ temperature · T temperature editor
  • Ctrl+Shift switch Basic / Extra tabs · h help
ℹ About & credits

Version 0.0.0 — project versioning uses X.Y.Z (major.minor.patch).

Awesome Periodic Table is a single self-contained HTML file — no build step, no server, no dependencies to install. Open it in any modern browser and it works, including offline.

Originally created and maintained by bert2020-dev. Source and issue tracker: github.com/bert2020-dev/awesome-periodic-table.

Everything runs client-side: element data is baked into this file in a compact custom format, and the search grammar, mouse modes, history system and autocomplete are all plain JavaScript with no external libraries.
